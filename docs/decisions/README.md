# Decisions

Esta carpeta registra decisiones significativas que afecten producto, arquitectura, integraciones, seguridad, contenido o mantenimiento.

Crear una decisión cuando:

- existan alternativas reales;
- la elección tenga consecuencias futuras;
- se incorpore o cambie un servicio externo;
- se defina una política relevante;
- sea importante conservar el contexto y las razones.

No crear ADR para cambios pequeños o evidentes.

Estados permitidos:

- Proposed;
- Accepted;
- Superseded;
- Rejected.

Usar template.md y numerar los archivos de manera secuencial:

- 0001-nombre-de-la-decision.md;
- 0002-nombre-de-la-decision.md.

No registrar una decisión como Accepted sin aprobación explícita.
